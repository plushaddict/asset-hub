保存时会试连 Bucket。AccessKey、Secret、businessToken 留空表示不修改，不会把脱敏串写回。

参数从哪里获取？（阿里云 OSS）
  1. 打开 对象存储 OSS 控制台 → 创建或进入目标 Bucket。
  2. 在 Bucket「概览」看 地域 Endpoint（外网，不要带 https://）和 Bucket 名称。
  3. URL 前缀：打开 Bucket →「概览」→「访问端口」表里的 Bucket 域名列（不要用「地域节点 / Endpoint」那一列）。 取外网访问对应域名，前面加 https://、末尾加 /，例如 https://my-bucket.oss-cn-beijing.aliyuncs.com/。 若已绑 CNAME / 自定义域名，也可填该行的域名（同样加 https:// 与 /）。 不要填内网（含 -internal）域名。公共读时用此前缀拼访问链接。
  4. AccessKey： RAM 访问控制 → 用户 → 创建 AccessKey （推荐子账号，勿用主账号 AK；Secret 只在创建时显示一次）。需具备该 Bucket 的读写权限（保存试连会调用 GetBucketInfo）。
  5. 私有读 / 签名有效期：与 Bucket 读写 ACL 一致。Bucket 为私有时勾选「私有读」，链接带时效签名；公共读可取消勾选，直接用 URL 前缀。
  6. businessToken：本系统自建口令，不是阿里云参数。业务方调 /api/business/asset 时用 query token 或请求头 X-Asset-Token；留空则不校验。
